==========================================================
ALEAPP USB PORTABLE FORENSIC KIT
==========================================================

This folder is 100% portable and self-contained. You can copy this 
entire folder onto any USB drive and run it on ANY Windows PC 
without installing Python, Git, or any dependencies.

CONTENTS:
1. aleappGUI.exe
   Standalone compiled binary of ALEAPP.
2. 1_Extract_Phone.bat
   Automated ADB tool to detect, connect, and extract data from 
   an Android phone connected via USB.
3. 2_Run_ALEAPP.bat
   One-click launcher for the ALEAPP graphical interface.
4. platform-tools\
   Official Google ADB and Fastboot utilities.

HOW TO USE:
Step 1: Connect your Android phone to the PC via USB.
Step 2: Double-click '1_Extract_Phone.bat' to pull artifacts/files.
Step 3: Double-click '2_Run_ALEAPP.bat'.
Step 4: Select the extracted data folder as the Input Path and click Process.
